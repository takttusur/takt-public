# TAKT IDENTITY

Это сервис отвечает за пользователей системы.
Но, он не должен отвечать за участников клуба и их статусы, роли, права, личные данные и т.д.

Грубо говоря, есть пользователь, у него есть имя пользователя и способ входа, сервис может выдать ему JWT токен.
Есть несколько видов пользователей: обычный и администратор, но это только в контексте этого сервиса.

### Что тут делаем?
- Регистрация пользователя
- Вход (выдача JWT токена)
- Рефреш токена
- Выход
- Сброс способа входа
- Получение информации о себе (свой логин по токену, мб что-то еще)
- Административные ендпоинты (посмотреть пользователей, заблокировать пользователя, пригласить пользователя)

### Как делаем? 
Используем core версию ASP.NET Identity.
Используем свою БД.
Стараемся не ходить в другие сервисы.
Другим сервисам отдаем публичную часть ключа. Приватной частью подписываем JWT-токен.
Работаем только с системными ролями, например пользователь и администратор.

### Что не делаем? 
- Не храним ФИО, дату рождения и другие данные связанные с человеком
- Не делаем тут роли: участник клуба, руководитель отделения, президент клуба, ответственный за склад и т.д.
