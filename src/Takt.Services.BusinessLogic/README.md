# TAKT SERVICES BUSINESS LOGIC

В этом проекте лежит бизнес-логика и доменные сущности. 
Например: 
- Пользователь
- Тренировка
- Склад
- Статья
- Маршрут

Что не нужно делать:
- Не кладите сюда объекты связанные с инфраструктурой или БД
- Не делайте этот проект зависимым от других проектов

Если нужно с чем-то работать из других проектов - создавайте интерфейс, но реализуйте его в нужном проекте. 
Далее через DI подключайте в API проекте.

‼️Всю бизнес логику тут нужно покрывать тестами. 
Если не получается что-то покрыть тестами, скорее всего как-то не так написано и нужно переписать.
